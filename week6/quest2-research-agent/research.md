## 동네골목 차별화 포인트 3가지

> 인사이트 원천: [`insights/2026-05-07-dongne-golmok-differentiation.md`](./insights/2026-05-07-dongne-golmok-differentiation.md) — *"동네 가게 발견의 4가지 양식"* 프레임

### 1. 광고 없는 큐레이션 — vs **당근**

당근의 매출 엔진은 *광고*. 비즈프로필 등록은 무료지만 "유의미한 단골"은 사실상 광고비 투입 필요. **사장님이 *돈 내고* 노출되는 동안, 동네골목은 *돈을 안 내도* 골목에 진짜 있는 50개 가게가 AI 비서로 자연스럽게 등장.** 4,300만 규모 당근이 *수익 모델 때문에 못 만드는 슬롯*.

### 2. 자연어 맥락 대화 — vs **네이버 플레이스**

네이버는 사용자가 *검색어를 정확히 만들 수 있을 때*만 작동. *"오늘 비 와서 따끈한 거 먹고 싶다"* 같은 *맥락 키워드*는 검색 박스에 들어가지 않음. **동네골목은 *검색어가 안 떠오르는 사용자*를 잡는다** — 카드 70개 비교 피로 대신 AI 비서가 3개 골라주는 흐름.

### 3. 책임지는 큐레이터 — vs **인스타그램**

인스타에서 *"나에게 맞는"* 가게를 고르는 건 사용자 몫. 신뢰의 출처가 *식객 채널*이라 *왜 좋은지*가 영상에 묻힘. **동네골목은 *큐레이터가 책임지고 50개를 골랐다*는 다른 종류의 신뢰 축** — 알고리즘 큐레이션과 다름.

## AUDIENCES.md 인풋 — 경쟁사 약점 → 동네골목이 메우는 자리

### 당근마켓 사용자 불만 패턴
- **"검색어로 표현 못 하면 못 찾는다"** — 검색·필터형 UX의 본질 한계 (당근의 "동네"는 행정동 단위라 같은 동 내 골목 단위 큐레이션은 사용자가 직접 후기 뒤져야 함)
- **광고 노출 피로** — 검색 상단·중고거래 홈 곳곳 광고. 자연 결과와 광고 시각적 구분 약함
- **광고 안 하는 가게는 묻힘** — 좋은 가게여도 광고비 안 쓰면 후순위. *"진짜 동네 좋은 가게"가 노출되지 않는* 역설
- **추천이 비-맥락적** — "에어컨" 검색 → 70건 카드. *오늘 같은 날 뭐 먹지*는 받아주지 않음

→ **동네골목이 메움**: 광고 없음 + 골목 단위 + 맥락 대화 = 위 4개를 한 번에 해소

### 네이버 플레이스 약점
- **별점 4.0~4.5 천장형 → 변별력 약함** — 사용자가 *진짜 좋은 곳*을 별점으로 못 가림. 결국 리뷰 수·TV 출연 등 *바이어스 신호*에 의존
- **광고와 자연 결과 구분 어려움** — "광고" 라벨은 있지만 시각적으로 약함. 첫 카드가 광고일 확률 높음
- **카드 70개 비교 피로** — 정보 밀도가 너무 높아 *결정 피로*가 검색 결과를 가림
- **개인 맥락 미지원** — "비 오는 날", "혼자", "데이트" 같은 맥락은 검색어가 아님

→ **동네골목이 메움**: 별점·리뷰 의존 X (큐레이터 책임) + AI가 *맥락에서 골라줌* (3개 응답) = 결정 피로 0

### 인스타그램 동네 채널 한계
- **같은 가게가 10명 인플루언서에게 등장해도 *왜* 좋은지 영상에 묻힘** — 캡션 텍스트는 짧고, 영상은 시청 후에야 판단 가능
- **협찬인지 자발인지 모호** — 인플루언서가 진짜 좋아서 올렸는지, 협찬받고 올렸는지 사용자 알 수 없음
- **알고리즘이 보여주는 거라 *내 맥락에 맞나* 불확실** — 인스타 알고리즘은 *내 일반 관심사* 기반, *지금 동네에서 뭐 먹지*가 아님
- **콘텐츠 채널이지 발견 채널은 아님** — 발견의 *동기 자체*가 다름 (시청 → 우연한 발견)

→ **동네골목이 메움**: *왜 골랐는지* AI가 한 문장으로 설명 + *책임 출처*가 큐레이터 (협찬 모호성 0) + *지금 내 맥락*으로 응답
